# StudentSkill Hub — Project Information Website

This is a Streamlit information website that explains the StudentSkill Hub group project. It is separate from the StudentSkill Hub desktop application.

## Important project description

StudentSkill Hub is a **Python Tkinter desktop application**. This Streamlit site is only an information/showcase website describing the project; it does not turn the original desktop project into a Streamlit application.

## Run locally

1. Extract the ZIP file.
2. Open this folder in VS Code.
3. Open the terminal in this folder (the folder containing `streamlit_app.py` and `requirements.txt`).
4. Install dependencies:

   ```powershell
   python -m pip install -r requirements.txt
   ```

5. Start the website:

   ```powershell
   python -m streamlit run streamlit_app.py
   ```

## Website sections

Home; Problem & Proposed Idea; Project Objectives; Target Users & Roles; Application Modules; Student Workflow; System Architecture; Data Organisation; Technology Stack; Implementation Highlights; Live Demonstration Plan; Limitations & Future Improvements; Conclusion & Sources.

## Accuracy notes

The website follows the group's project presentation. It describes the current prototype as using Tkinter, pandas DataFrames and in-memory sample data. It does not claim that the project currently uses a persistent database or is deployed as a multi-user web service. SQLite and other enhancements are shown only as future improvements, as in the project presentation.
